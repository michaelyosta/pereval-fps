# Baseline QA

## Что проверено

- стартовый экран;
- общий вид уровня;
- demo mode `?demo=1`;
- базовый HUD и оружие.

## Что наблюдалось

- Сцена и HUD отображаются.
- Demo-камера и автоматическая стрельба работают.
- В обычном режиме после запуска Pointer Lock в тестовом браузере не захватился, но fallback продолжил показывать игру.
- В demo-сеансе появился неожиданный Chromium `UnknownError`; это требует устранения/изоляции в тестовом окружении.

## Метрики

Исходный прототип не публикует FPS, draw calls, triangles или размеры ресурсов. Значения оставлены неизвестными до добавления измеряемого debug/benchmark API; фиктивные цифры не используются.

## QA-артефакты

Снимки baseline сохраняются в этом каталоге после инструментирования захвата. Сравнение после изменений будет выполняться при одинаковом разрешении и demo-камере.
